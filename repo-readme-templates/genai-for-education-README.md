## Overview

This repository can serve as a teaching innovation hub containing prompt templates, classroom activities, assessment design tools, course planning resources, and GenAI-enabled academic experiments.

---

## Key Features

- Prompt libraries for faculty and students
- Assessment-resistant assignment design
- Course planning templates
- Classroom activity frameworks
- Responsible AI use guidelines

## Getting Started

```bash
git clone https://github.com/dr-alok-tiwari/genai-for-education.git
cd genai-for-education
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
