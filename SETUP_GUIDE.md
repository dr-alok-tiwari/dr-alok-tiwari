# Premium GitHub Profile Setup Guide

## 1. Create the GitHub profile repository

Create a repository with exactly this name:

```text
dr-alok-tiwari
```

It must match your GitHub username exactly for GitHub to show the README on your profile.

## 2. Upload these files

Upload the following structure:

```text
dr-alok-tiwari/
├── README.md
├── assets/
│   ├── banner.svg
│   └── footer-wave.svg
├── repo-readme-templates/
│   ├── healthcare-analytics-README.md
│   ├── medical-imaging-ai-README.md
│   ├── ai-research-assistant-README.md
│   ├── genai-for-education-README.md
│   ├── data-visualization-dashboard-README.md
│   └── academic-portfolio-website-README.md
└── extras/
    ├── github-bio.txt
    ├── pinned-repo-descriptions.txt
    └── color-palette.md
```

## 3. Update personal links

## 6. Git commands

From your local folder:

```bash
git init
git add .
git commit -m "Add premium GitHub profile README"
git branch -M main
git remote add origin https://github.com/dr-alok-tiwari/dr-alok-tiwari.git
git push -u origin main
```

## 7. Design logic

The selected palette is intentionally premium and professional:

- Deep navy: academic seriousness and credibility
- Royal blue: technology and trust
- Cyan: AI and innovation
- Violet: creativity and intelligence
- Gold: achievement, scholarship, and distinction

Do not overload the profile with too many animations. Your best positioning is not only as a programmer, but as an academic AI researcher and applied analytics builder.
